# Contributing

Please report any issues or suggestions on the [GitHub issue tracker](https://github.com/crossplane-assistant/readthedocs/issues).

When an issue is reported, the team will review it and provide feedback. If the issue is accepted, the team will assign it to a team member to work on it.

You can also work on identified issues and submit a pull request. The team will review the pull request and provide feedback. If the pull request is accepted, the team will merge it.

We thank you in advance for your contributions on the project.

## Local environment

We use [`poetry`](https://python-poetry.org/) to manage the project dependencies and isolate python libraries.

Prepare environment.

```bash
poetry install
```

Run the mkdocs server locally to preview changes.

```bash
poetry run mkdocs serve
```

Go to [http://localhost:8000](http://localhost:8000) to view the documentation.
